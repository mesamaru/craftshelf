# セキュリティ / Security

## 脆弱性の報告

CraftShelf に脆弱性を見つけた場合は、公開の Issue には書かず、GitHub の
[Security Advisories(非公開の報告)](https://github.com/mesamaru/craftshelf/security/advisories/new)
から報告してください。内容を確認し、修正版を公開してからお知らせします。

報告には、再現手順・影響する版・想定される影響を含めていただけると助かります。

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately via
[GitHub Security Advisories](https://github.com/mesamaru/craftshelf/security/advisories/new).
Include steps to reproduce, the affected version and the expected impact.

## 対応する版 / Supported versions

最新の版のみ修正します。/ Only the latest release receives security fixes.
