# 画面の決まり(03.68.00 から。v02 の作りと使い勝手に合わせる。03.69.00 でサーバー・セット・設定・ホームのウィジェットまで。03.73.02 で名前・タイトル・大きさと日付・そろえる結果を整理)

手本は v02 の画面(`main` の `static/`)。Apple の Liquid Glass(iOS 26 以降)を参考にした、半透明のガラス・グループリスト・カプセル型のボタン。明るい・暗いの両方で見る。迷ったら v02 の並び・形・言葉に合わせ、文言だけは下の「文言」の決まり(短く・長い説明は ⓘ)を守る。

## 色・角・影は変数で

- `src/styles.css` の `:root` にまとめている(`--glass`・`--glass2`・`--sheet`・`--line`・`--chip`・`--chip2`・`--text`・`--muted`・`--accent`・`--accent-ink`・`--accent-soft`・`--ok`・`--warn`・`--danger`・`--shadow`・`--r-card`(22 px)・`--r-sheet`(30 px)・`--r-ctl` など)。値は v02 の `app.css` と同じ(明るいときは白いカード、暗いときは `#1c1c1e` のカードを 76% の濃さで重ねる)。暗いときの値は `@media (prefers-color-scheme: dark)` と `[data-theme="dark"]` の 2 か所に書く。
- テーマ(`src/lib/theme.ts`)は v02 の 8 テーマ(オーロラ・サンセット・オーシャン・オーバーワールド・ネザー・ジ・エンド・パステル・グラファイト)と標準(v02 のミント)。`--bg`・`--accent`・`--accent-ink` と `data-theme` を上書きするだけ。初めは v02 と同じオーロラ(緑・暗い背景)。暗さ・ぼかし・背景画像もそのまま効く。
- アクセントで塗ったところの文字は `--accent-ink`(明るい色には暗い文字。v02 の緑のボタンの黒っぽい文字)。`#fff` を直接書かない。色を足すときは `--accent` から `color-mix()` で作る(100% を超える割合は書かない。効かなくなる)。
- `-webkit-backdrop-filter` は書かない(`backdrop-filter` だけ書けば、ビルドが両方を出す。両方書くと Chrome で効かなくなる)。

## 設定の並べ方

- めったに変えないものは 1 行ずつ(`Row` に名前と今の値の `.sub`、右に `›`)並べ、押すと右のシートで変える(サーバーの詳細の「設定」タブ)。消すなど危ないものは下の「危ない操作」にまとめる。
- 設定の画面は 2 段(`src/lib/settings-frame.tsx` の `SettingsFrame`)。左にまとまりの一覧、右に中身。一覧の分け方と言葉は v02 の設定(歯車)と同じ: 上に自分(名前・役割 → プロフィール)、セキュリティ・管理・連携・運用・ツール・サポート・表示・CraftShelf、色つきの四角(`.cicon`。`c-plugin` 青・`c-mod` 緑・`c-datapack` 橙・`c-resourcepack` 紫・`c-teal`・`c-other`)と ›、下に「ログアウト」。スマホ(720 px まで)は、`/settings` を何も選ばずに開くと一覧だけ(`root`)、まとまりを開くと中身と「‹ 設定」。
  - まとまりを足すときは、`SettingsFrame` の `useGroups` に 1 行(`e(key, 名前, アイコン, 色, URL, 出す条件, ?s=)`)を足し、画面の側で `<SettingsFrame at="key" info={…}>` で包む。`/settings`・`/team` の中のまとまりは `?s=` で選ぶ(`SECTIONS` に足す)。別の URL の画面(`/backup` など)は、その画面がそのまま包む。
  - 出す条件は権限(`can`)と版(`app.mode`)。使えないまとまりは出さない(サーバー側でも必ず確かめる)。
  - 見出しはまとまりの名前を枠が出す(画面の中に同じ名前の `gtitle` を重ねない)。まとまり全体の説明は `info`、部分の説明は `gtitle` の `Info`。

## 文言

- 短く: 「検索」「前提不足」「要確認」「稼働中」「すべて更新」「＋ 追加」「そろえる」「2 件」「タグ」「セットへ」「入れる」「外す」。ボタンは動詞 1 つ、見出しは名詞 1 つ。v02 にある言葉(「はじめの設定」「ドラッグ&ドロップで追加」「保存しているバージョン」など)は v02 に合わせる。
