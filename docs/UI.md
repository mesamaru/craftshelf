# 画面の決まり(03.68.00 から。v02 の作りと使い勝手に合わせる)

手本は v02 の画面(`main` の `static/`)。Apple の Liquid Glass(iOS 26 以降)を参考にした、半透明のガラス・グループリスト・カプセル型のボタン。明るい・暗いの両方で見る。迷ったら v02 の並び・形・言葉に合わせ、文言だけは下の「文言」の決まり(短く・長い説明は ⓘ)を守る。

## 色・角・影は変数で

- `src/styles.css` の `:root` にまとめている(`--glass`・`--glass2`・`--sheet`・`--line`・`--chip`・`--chip2`・`--text`・`--muted`・`--accent`・`--accent-ink`・`--accent-soft`・`--ok`・`--warn`・`--danger`・`--shadow`・`--r-card`(22 px)・`--r-sheet`(30 px)・`--r-ctl` など)。値は v02 の `app.css` と同じ(明るいときは白いカード、暗いときは `#1c1c1e` のカードを 76% の濃さで重ねる)。暗いときの値は `@media (prefers-color-scheme: dark)` と `[data-theme="dark"]` の 2 か所に書く。
- テーマ(`src/lib/theme.ts`)は v02 の 8 テーマ(オーロラ・サンセット・オーシャン・オーバーワールド・ネザー・ジ・エンド・パステル・グラファイト)と標準(v02 のミント)。`--bg`・`--accent`・`--accent-ink` と `data-theme` を上書きするだけ。初めは v02 と同じオーロラ(緑・暗い背景)。暗さ・ぼかし・背景画像もそのまま効く。
- アクセントで塗ったところの文字は `--accent-ink`(明るい色には暗い文字。v02 の緑のボタンの黒っぽい文字)。`#fff` を直接書かない。色を足すときは `--accent` から `color-mix()` で作る(100% を超える割合は書かない。効かなくなる)。
- `-webkit-backdrop-filter` は書かない(`backdrop-filter` だけ書けば、ビルドが両方を出す。両方書くと Chrome で効かなくなる)。

## 全体の枠(`src/lib/shell.tsx`)

- ログインした画面だけ(`showShell`。ログイン・登録・招待・パスワード・利用規約・プライバシーには出さない)。
- パソコン(幅 1000 px から): 左のメニュー(ブランド「CraftShelf v03」と ‹・ライブラリ(件数)・ホーム・セット・サーバー(その下に各サーバーと稼働の点。8 台まで)。下に お知らせ(未読の数)・設定・自分(名前と役割))と、上のバー(検索 = Ctrl K の `src/lib/palette.tsx`・緑の「＋ 追加」・読み直し)。
  - ‹ で畳むとアイコンだけの細いメニュー(v02 と同じ。Ctrl B でも。`<html class="side-mini">` とこの端末の localStorage)。
  - 本文はメニューの右の場所の中央に、上のバーと同じ幅(1180 px まで)でそろえる。表の画面(比較・ポート)は `page wide` で幅いっぱい。
- 幅 1000 px まで: 上のバー(名前・読み直し・お知らせ・設定)と下のタブ(ライブラリ・セット・＋・ホーム・サーバー)。検索は見出しの下(`MobileSearch`)。720 px までは下のタブを横いっぱいに。
- お知らせは右のシートで開く(開くと既読)。比較・処理の一覧などメニューに無い画面は、サーバーの画面と検索から開く。
- 見出しは大きく(34 px・太字)。メニューの画面(ライブラリ・ホーム・セット・サーバー)は、見出しの右に保存先の印(`StoragePill`。自分用の版だけ。「● ローカル」)と、その下にスマホの検索(`MobileSearch`)を置く。
- 画面の中に「戻る」は置かない(メニューで移る)。メニューに無い画面(サーバー本体・ポート・アドオンの整理など)だけ、上に「‹ 親の画面」(`a.back`)を置く。

## ライブラリ(`src/routes/index.tsx`)= アドオンの管理

- 並び(v02 と同じ): 見出しと保存先の印 / はじめの設定(管理者だけ・✕ で閉じる・「あとで」「使わない」はこの端末に残す)/ ドラッグ&ドロップで追加の欄(自分用の版・編集者以上。ファイルを選択・フォルダ・配布サイトで探す)/ 数のカード(更新あり・前提不足。押すと確かめて絞り込む)/ 絞り込みの欄(検索・配布元・MC・選択・並べ替え、その下に種類ごとの件数・お気に入り・タグ)/ 一覧。
- 一覧の行: アイコン(種類の色。プラグイン = 青・Mod = 緑・データパック = 橙・リソースパック = 紫)・名前 ☆・タグ・「版 · N バージョン · 大きさ · 日付」・印(更新あり・前提不足)・›。
- **どのサーバーに入っているかは、一覧にも詳しくにも出さない**(サーバーの画面で見る)。サーバーに入れるのは「選択」で選んだときの操作のバーの「入れる」か、詳しくの ⋯ の「サーバーに入れる…」で、入れる先を選ぶ。足りない前提は「N 台に足りません」とだけ出し、足りないサーバーすべてに入れる。
- 詳しく(右のシート。`?item=` に残し、戻るボタンで閉じる): 種類の印・✎(情報を直す。管理者)・⋯ / アイコン・名前 ☆・版の情報 / タグ / 配布元 / 共有 / 保存しているバージョン(新しい順・ダウンロード・削除・保存の設定)/ 前提 / 変更内容 / 情報。

## ホーム(`src/routes/home.tsx`)

- v02 のダッシュボード: 数のカード(登録しているもの・使っている容量・更新があるもの・配布元の連携)、2 列のカード(更新があるもの・最近追加したもの / 種類ごとの件数・確認が必要なもの(整理へ)・サーバー(管理している数・同期の状態)・配布元の連携)。
- 更新は配布元に問い合わせるので、「今すぐ確認」を押したときだけ確かめる。一覧は 4 件まで、あとは「もっと見る」でライブラリへ。

## 設定の並べ方

- めったに変えないものは 1 行ずつ(`Row` に名前と今の値の `.sub`、右に `›`)並べ、押すと右のシートで変える(サーバーの詳細の「設定」タブ)。消すなど危ないものは下の「危ない操作」にまとめる。
- 設定の画面(アカウント・チーム・パネル)は 2 段(`src/lib/settings-frame.tsx` の `SettingsFrame`)。左にまとまりの一覧、右に中身。スマホ(720 px まで)は、`/settings` を何も選ばずに開くと一覧だけ(`root`)、まとまりを開くと中身と「‹ 設定」。
  - まとまりを足すときは、`SettingsFrame` の `useGroups` に 1 行(`key`・名前・URL・`?s=`・出す条件)を足し、画面の側で `<SettingsFrame at="key" info={…}>` で包む。`/settings`・`/team` の中のまとまりは `?s=` で選ぶ(`SECTIONS` に足す)。別の URL の画面(`/backup` など)は、その画面がそのまま包む。
  - 出す条件は権限(`can`)と版(`app.mode`)。使えないまとまりは出さない(サーバー側でも必ず確かめる)。
  - 見出しはまとまりの名前を枠が出す(画面の中に同じ名前の `gtitle` を重ねない)。まとまり全体の説明は `info`、部分の説明は `gtitle` の `Info`。

## 文言

- 短く: 「検索」「前提不足」「要確認」「稼働中」「すべて更新」「＋ 追加」「そろえる」「2 件」「タグ」「セットへ」「入れる」「外す」。ボタンは動詞 1 つ、見出しは名詞 1 つ。v02 にある言葉(「はじめの設定」「ドラッグ&ドロップで追加」「保存しているバージョン」など)は v02 に合わせる。
- 長い説明は `Info` に。確かめ(`confirm`)・失敗の理由は、これまでどおり文で書く。
- 新しい日本語は `src/lib/i18n-en.ts` に英訳を足す(短い言葉は `EN_WHOLE`、数字の入る文は `EN_RULES`)。英語は長くなるので、英語でも 1 行に収まるか見る。

## 折り返し

- 全体に `word-break: auto-phrase; text-wrap: pretty; line-break: strict;`(言葉の途中で折らない)。
- 見出し・ボタン・丸いボタン・メニュー・タブ・印は `word-break: keep-all`(折らない)。名前・説明は `.mid` の中で `…` で切る。
