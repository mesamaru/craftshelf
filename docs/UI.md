# 画面の決まり(03.65.00 から)

Apple の Liquid Glass(iOS 26 以降)を参考にした、半透明のガラス・グループリスト・カプセル型のボタン。明るい・暗いの両方で見る。

## 色・角・影は変数で

- `src/styles.css` の `:root` にまとめている(`--glass`・`--glass2`・`--line`・`--chip`・`--text`・`--muted`・`--accent`・`--accent-soft`・`--ok`・`--warn`・`--danger`・`--shadow`・`--r-card`・`--r-sheet`・`--r-ctl` など)。暗いときの値は `@media (prefers-color-scheme: dark)` と `[data-theme="dark"]` の 2 か所に書く。
- テーマ(`src/lib/theme.ts`)は `--bg`・`--accent` と `data-theme` を上書きするだけ。色を足すときは `--accent` から `color-mix()` で作り、決まった青を直接書かない。
- `-webkit-backdrop-filter` は書かない(`backdrop-filter` だけ書けば、ビルドが両方を出す。両方書くと Chrome で効かなくなる)。

## 全体の枠(`src/lib/shell.tsx`)

- ログインした画面だけ(`showShell`。ログイン・登録・招待・パスワード・利用規約・プライバシーには出さない)。
- パソコン: 左のメニュー(ライブラリ・セット・サーバー(各サーバーと稼働の点)・比較・設定・自分。チームは設定の中)と、上の検索(Ctrl K。`src/lib/palette.tsx`)・処理の一覧・お知らせ・「＋ 追加」。
- スマホ(幅 720 px まで): 下のタブ(ライブラリ・セット・＋・サーバー・その他)と、上の小さな検索・お知らせ。
- 画面の中に「戻る」は置かない(メニューで移る)。メニューに無い画面(サーバー本体・ポート・アドオンの整理など)だけ、上に「‹ 親の画面」(`a.back`)を置く。

| --- | --- |

| `.hero`・`.stats` | 詳しい画面の上の見出しの欄(アイコン・名前・状態・操作)と、数字のタイル |

## 設定の並べ方

- めったに変えないものは 1 行ずつ(`Row` に名前と今の値の `.sub`、右に `›`)並べ、押すと右のシートで変える(サーバーの詳細の「設定」タブ)。消すなど危ないものは下の「危ない操作」にまとめる。

- 設定の画面(アカウント・チーム・パネル)は 2 段(`src/lib/settings-frame.tsx` の `SettingsFrame`)。左にまとまりの一覧、右に中身。スマホ(720 px まで)は、`/settings` を何も選ばずに開くと一覧だけ(`root`)、まとまりを開くと中身と「‹ 設定」。
  - まとまりを足すときは、`SettingsFrame` の `useGroups` に 1 行(`key`・名前・URL・`?s=`・出す条件)を足し、画面の側で `<SettingsFrame at="key" info={…}>` で包む。`/settings`・`/team` の中のまとまりは `?s=` で選ぶ(`SECTIONS` に足す)。別の URL の画面(`/backup` など)は、その画面がそのまま包む。
  - 出す条件は権限(`can`)と版(`app.mode`)。使えないまとまりは出さない(サーバー側でも必ず確かめる)。
  - 見出しはまとまりの名前を枠が出す(画面の中に同じ名前の `gtitle` を重ねない)。まとまり全体の説明は `info`、部分の説明は `gtitle` の `Info`。

## 文言

- 短く: 「検索」「前提不足」「要確認」「稼働中」「すべて更新」「＋ 追加」「そろえる」「2 件」「タグ」「セットへ」「入れる」「外す」。ボタンは動詞 1 つ、見出しは名詞 1 つ。
- 長い説明は `Info` に。確かめ(`confirm`)・失敗の理由は、これまでどおり文で書く。
- 新しい日本語は `src/lib/i18n-en.ts` に英訳を足す(短い言葉は `EN_WHOLE`、数字の入る文は `EN_RULES`)。英語は長くなるので、英語でも 1 行に収まるか見る。

## 折り返し

- 全体に `word-break: auto-phrase; text-wrap: pretty; line-break: strict;`(言葉の途中で折らない)。
- 見出し・ボタン・丸いボタン・メニュー・タブ・印は `word-break: keep-all`(折らない)。名前・説明は `.mid` の中で `…` で切る。
