# 画面の決まり(03.65.00 から)

Apple の Liquid Glass(iOS 26 以降)を参考にした、半透明のガラス・グループリスト・カプセル型のボタン。明るい・暗いの両方で見る。

## 色・角・影は変数で

- `src/styles.css` の `:root` にまとめている(`--glass`・`--glass2`・`--line`・`--chip`・`--text`・`--muted`・`--accent`・`--accent-soft`・`--ok`・`--warn`・`--danger`・`--shadow`・`--r-card`・`--r-sheet`・`--r-ctl` など)。暗いときの値は `@media (prefers-color-scheme: dark)` と `[data-theme="dark"]` の 2 か所に書く。
- テーマ(`src/lib/theme.ts`)は `--bg`・`--accent` と `data-theme` を上書きするだけ。色を足すときは `--accent` から `color-mix()` で作り、決まった青を直接書かない。
- `-webkit-backdrop-filter` は書かない(`backdrop-filter` だけ書けば、ビルドが両方を出す。両方書くと Chrome で効かなくなる)。

## 全体の枠(`src/lib/shell.tsx`)

- ログインした画面だけ(`showShell`。ログイン・登録・招待・パスワード・利用規約・プライバシーには出さない)。
- パソコン: 左のメニュー(ライブラリ・セット・サーバー(各サーバーと稼働の点)・比較・チーム・設定・自分)と、上の検索(Ctrl K。`src/lib/palette.tsx`)・処理の一覧・お知らせ・「＋ 追加」。
- スマホ(幅 720 px まで): 下のタブ(ライブラリ・セット・＋・サーバー・その他)と、上の小さな検索・お知らせ。
- 画面の中に「戻る」は置かない(メニューで移る)。メニューに無い画面(チームの下の保存先など)だけ、上に「‹ 親の画面」を置く。

## 部品(`src/lib/ui.tsx`)

| 部品 | 使うところ |
| --- | --- |
| `Btn`(`.btn`) | `pri` = その画面でいちばん大事な 1 つ / `sec` = ふつう / `tint` = すすめる操作(更新・入れる)/ `red` = 消す・外す。行・バーの中は `sm` |
| `Chip`(`.chip`) | 絞り込み・選ぶもの・タグ。`on` = 選んでいる、`warn` = 気を付けるもの |
| `ChipBar` + `Tool` | 一覧の上の絞り込みの欄。丸いボタンは 1 行(横に流す・右端は薄く消す・ホイールで横に動く)。右に「絞り込み(数)」「並べ替え」を固定(スマホはアイコンだけ) |
| `.group` + `.row` / `Row` | グループリスト。押せる行は `Row onClick`(`.row.click`)。中身は `.mid` に `.ttl`(名前)と `.sub`(種類 · 配布元 などの小さな説明) |
| `Seg` | シートの中のタブ・並べ替え |
| `Sheet` | 詳しく・追加・絞り込み。右から(スマホは下から)。外を押す・Esc・✕ で閉じる |
| `ActionBar` | 一覧でチェックしたときに下に出る操作のバー(`N 件` と短いボタン) |
| `Info` | ⓘ。説明は画面に出しっぱなしにせず、ここにしまう |
| `.badge.upd` / `.ok` / `.bad` | 印(更新あり・最新・前提不足) |

## 文言

- 短く: 「検索」「前提不足」「要確認」「稼働中」「すべて更新」「＋ 追加」「そろえる」「2 件」「タグ」「セットへ」「入れる」「外す」。ボタンは動詞 1 つ、見出しは名詞 1 つ。
- 長い説明は `Info` に。確かめ(`confirm`)・失敗の理由は、これまでどおり文で書く。
- 新しい日本語は `src/lib/i18n-en.ts` に英訳を足す(短い言葉は `EN_WHOLE`、数字の入る文は `EN_RULES`)。英語は長くなるので、英語でも 1 行に収まるか見る。

## 折り返し
