### ダウンロード / Downloads

| OS | ファイル | 使い方 |
| --- | --- | --- |
| Windows 10 / 11 | `CraftShelf-Setup-*.exe` | 実行してインストール。タスクトレイのアイコンから開けます |
| macOS(Apple シリコン) | `CraftShelf-*-macos-arm64.dmg` | 開いて CraftShelf を「アプリケーション」へドラッグ |
| macOS(Intel) | `CraftShelf-*-macos-x64.dmg` | 同上 |
| Ubuntu / Debian(サーバー) | `install.sh` | `curl -fsSL https://raw.githubusercontent.com/mesamaru/craftshelf/main/install.sh \| sudo bash` |
| Linux(デスクトップ) | `CraftShelf-*-linux-x64.tar.gz` | 展開して `CraftShelf` を実行 |
| Docker | — | README の「導入(Docker)」を参照 |

初回起動時に「発行元を確認できません」という警告が出ることがあります(コード署名をしていないため)。
Windows は「詳細情報 → 実行」、macOS は CraftShelf を右クリック →「開く」で起動できます。
